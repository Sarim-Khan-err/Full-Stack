This assignment uses HTML, Bootstrap, and plain JavaScript. It is a browser-only demonstration with one signed-in demo account. It makes no server calls. Its playful campus noticeboard uses bright colors and a small cat illustration, while keeping the main actions clearly labeled.

## Run it

1. Open `login.html` in a browser.
2. Sign in as `sarim` with password `meadow123`.
3. Use Home, People, Messages, and My profile to try the interactions.
4. On Home, choose **Reset demo data** to restore the sample.

The app saves sample posts, reactions, ratings, requests, and messages in this browser using `localStorage`. Messages show as sent in the current member's conversation; they are not delivered to a second login.

## Assignment features

- Login screen, member profile, and a friends list.
- Friend feed ordered by each friend's latest login.
- Sharing text updates with all friends or selected friends.
- Friend requests that can be sent, accepted, and declined.
- Request blocking when a member ignores the sender.
- Private friend ratings: Stupid, Cool, and Trustworthy.
- Like and dislike controls with counts.
- Private message conversations with friends and other members.
- Responsive Bootstrap layout, error messages, and browser saved demo data.
