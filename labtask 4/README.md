# Lab Task 4 — JavaScript Practice

Open `index.html` in a browser. The six solutions are in `script.js`; results appear on the page and in the browser console.

## Tasks

1. Biography built from primitive `var` variables and an object with nested address and degree program objects. The console prints selected fields. Replace the sample age, address, and degree details with your own.
2. `nextPrimeAfter` validates the supplied prime and uses loops to find its successor. The example starts at 11 and returns 13.
3. `formatPhoneNumber` validates a ten-element array of digits and formats it as `(XXX) XXX-XXXX`.
4. `roundMe` returns 0 with no arguments, a number with one, and an array with multiple values.
5. `abs`, `ceil`, and `floor` are custom helpers that accept zero or more numeric arguments, following the same result shape as Task 4.
6. `sumMultiples(x, y, z)` adds positive multiples of `x` or `y` below `z`, counting a number once when it is a multiple of both. The example returns 23 for `(3, 5, 10)`.

The page uses no external libraries or network assets.
